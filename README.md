## Ingredients

- Made with Vite + React Router v7 (prerendering + SSG); Tailwind; and other assorted libraries for utility.
- 3D/rendering libraries include three.js, VANTA, etc.
- Icons from lucide + branded ones e.g. GitHub logo from SimpleIcons
- Plenty of creative inspiration from other well-designed apps & sites (see below!)

*For more information, please read `package.json`.*

## Inspo

- Fluid gradient text effect with moving colours in the hero was inspired by Animex's similarly animated hero text
- Hyperlink design inspired by Polestar's website
- Hero background gradient colours are meant to resemble a subtle, stylized sunrise emerging from a night sky (originally was going to be a full shader sky); inspired by unity's HDRP PBS
- General layout inspired by Anduril's site
- ChatGPT, Claude and Gemini's advice
- Various awwwwards winners
